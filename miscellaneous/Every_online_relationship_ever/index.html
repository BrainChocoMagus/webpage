    ================================================================
    ✏️ DEVELOPER INSTRUCTIONS - HOW TO EDIT AI RESPONSES
    ================================================================
    
    You are the only one who sees this. To customize the AI behavior:
    
    1. Open your browser's Developer Tools (F12) and go to the Console tab.
    2. Type: window.__EDIT_AI_RESPONSES__ and press Enter.
       You'll see the current response arrays.
    
    3. Alternatively, edit the JavaScript file (or this HTML's JS section) and modify:
       - warmResponses: kind replies before ghosting
       - ghostResponses: cold replies during ghosting
       - specialKeywords: custom trigger words
    
    =========== QUICK EDIT EXAMPLE ===========
    window.warmResponses.push("💖 You mean the world to me!");
    window.ghostResponses.push("...seen");
    
    Or edit the "AI_CONFIG" object directly in the JS source.
    
    The AI responses are stored in the global window.__AI_CONFIG__
